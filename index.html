Email alerts

Direct email notifications

Checks run each time AeroDocs opens (and on manual check). One digest email is sent per milestone crossed; each milestone is sent once per document expiry date.

In the EmailJS template set To Email to {{to_email}}, Subject to {{subject}}, body to {{message}}. Restrict the template to your own address in the EmailJS dashboard.

Resend blocks direct browser calls and the API key must never sit in client code. Upload the included resend-relay.php to your hosting; it holds the key server-side.
